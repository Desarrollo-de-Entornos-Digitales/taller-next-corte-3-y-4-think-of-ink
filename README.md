# Think of Ink

Think of Ink es una red social comercial enfocada tanto en tatuadores como en estudios y personas interesadas en hacerse tatuajes, en ella pueden publicar, comentar e interactuar para hacer todo el proceso para informarse sobre los tatuajes de una forma más cómoda y directa.


## Características
*   Interfaz moderna y responsiva.
*   Navegación intuitiva.


## Tecnologías
*   *React / Next.js*
*   *TypeScript*
*   *Tailwind CSS*

## Instalación

1. Clona el repo:
   git clone https://github.com/tu-usuario/tu-proyecto.git
2. Instala dependencias:
   npm install
3. Corre el proyecto:
   npm run dev

## Instrucciones del uso de la página 

1. Acceder a la página de Register 
2. Completar el formulario de Register
3. Acceder al Login
4. Completar formulario del Login
5. Acceder al feed
6. Opción 1: Acceder al apartado de rango de precios
7. Opción 2: Acceder al apartado de localización
8. Opción 3: Acceder al apartado de categorías
9. (Despues de seleccionar opción 1) Determinar en la escala el rango de precio que se desea ver
10. Consultar la información de los estudios arrojados
11. (Después de seleccionar opción 2) Utilizar el mapa para determinar tu localización deseada
12. Ver y consultar los perfiles de los tatuadores/ estudios cercanos de interés
13. (Después de seleccionar opción 3) Determinar la categoría deseada, seleccionar la publicación de interés
14. Acceder al perfil propio
15. Consultar información del usuario y/o modificarla 
16. Ir al apartado de publicaciones propias del perfil y administrarlas (borrarlas y demás)
17. Dirigirse al apartado de crear nueva publicación 
18. Completar los campos obligatorios del formulario y publicar lo necesario
19. En caso de consultar info de otro ususario, seleccionar una publicación de interés del usuario deseado y darle click a su ícono
20. Consultar la info disponible del usuario (publicaciones, ubicación, nombre, etc)
21. Seleccionar publicación de interés
22. Seleccionar apartado de comentarios 
23. Llenar campode texto de comentario
24. Publicar
25. Buscar publicación de interés
26. Darle al botón de me gusta
